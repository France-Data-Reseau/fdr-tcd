# Guide de l'utilisateur — Cartographie des Usages TCD (FNCCR)

> Pour les agents de collectivités qui **saisissent** les données de leurs projets
> « Territoires Connectés Durables » et **consultent** la cartographie. Aucune
> compétence technique requise.

---

## 1. À quoi sert la plateforme

Elle rassemble et met en carte les **projets numériques des collectivités**
(capteurs, réseaux, cas d'usage…). Vous pouvez :
- **contribuer** : décrire les projets de votre collectivité ;
- **consulter** : explorer la carte et les statistiques de tous les territoires.

## 2. Se connecter

1. Ouvrez l'adresse de la plateforme dans votre navigateur.
2. Cliquez sur **« Se connecter avec France Data Réseau »**.
3. Saisissez vos identifiants France Data Réseau.
4. Vous arrivez sur la page d'accueil.

> Il n'y a **pas de mot de passe spécifique** à cette plateforme : tout passe par
> votre compte France Data Réseau.
>
> **« Accès non autorisé » ?** Votre compte n'a pas encore été activé pour la
> plateforme : contactez un administrateur FNCCR (il doit vous ajouter et vous
> rattacher à votre collectivité).

## 3. La page d'accueil

Deux (ou trois) grandes tuiles :
- **Contribution** — saisir et modifier les données ;
- **Cartographie** — voir les cartes et statistiques ;
- *(Console Administrateur — seulement si vous êtes administrateur).*

---

## 4. Contribuer : saisir les données de votre collectivité

### a. Choisir votre collectivité
Accueil → **Contribution**. Recherchez et cliquez sur **votre collectivité**
(vous ne pouvez modifier que la vôtre). *(Un administrateur peut, si besoin,
créer une nouvelle collectivité via « + Créer une nouvelle collectivité ».)*

### b. Compléter le profil de la collectivité
Renseignez les champs (nom, SIREN, statut, couverture, **département**, site web,
adresse) puis **« Enregistrer les modifications »**. La région et le numéro de
département se calculent **automatiquement**.

### c. Ajouter / modifier un projet
Sur la page de votre collectivité, vous voyez la liste de vos projets. Cliquez
sur un projet pour le modifier, ou sur **« + Ajouter un projet »**.

Un projet décrit : nom, description, avancement, échelle, **connectivité(s)**,
**mutualisation**, **financements**, **contrat(s)**, **solution(s)**,
**département(s) concerné(s)**… Les listes de choix sont prédéfinies — il suffit
de sélectionner *(astuce : Ctrl/Cmd + clic pour en choisir plusieurs)*.

> Les **thèmes** d'un projet se calculent tout seuls à partir de ses **cas
> d'usage** — vous n'avez pas à les saisir.

### d. Enrichir un projet (cas d'usage, partenaires, etc.)
Depuis un projet, vous pouvez ajouter :
- des **cas d'usage** (ce que fait concrètement le projet) ;
- des **partenaires**, des **programmes**, des **documents**, des **contacts**.

Chaque ajout se fait via un petit formulaire dédié, puis s'enregistre.

---

## 5. Consulter la cartographie

Accueil → **Cartographie**. Vous obtenez :
- une **carte de France** avec les collectivités (cliquez un point pour le détail) ;
- des **compteurs** (nombre de collectivités, de projets, de cas d'usage) ;
- des **filtres** (couverture, type de collectivité, thème, connectivité,
  avancement) pour affiner l'affichage.

C'est une **vue de consultation** : tout le monde y voit l'ensemble des
territoires (les coordonnées des personnes ne sont jamais affichées).

## 6. Se déconnecter

En haut de page → **« Se déconnecter »**.

---

## 7. Questions fréquentes

- **Je ne vois pas le bouton « Contribution ».** Vous êtes peut-être en droit
  « Visiteur » (consultation seule) — demandez à un administrateur de vous passer
  « Éditeur ».
- **Je ne peux pas modifier une autre collectivité que la mienne.** C'est normal :
  chaque éditeur ne gère que sa collectivité.
- **Une collectivité est mal placée sur la carte.** Signalez-le à un
  administrateur : la position peut être corrigée.
